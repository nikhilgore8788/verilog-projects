## Projects

### 1. 4:1 Multiplexer

A 4:1 Multiplexer selects one of four input signals based on two select lines.

**Inputs:** D0, D1, D2, D3  
**Select Lines:** S0, S1  
**Output:** Y

### Verilog Code

The Verilog implementation is available in:

`4_to_1_mux.v`
